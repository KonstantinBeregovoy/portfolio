## Problem

Dates and time zones in JavaScript still depend on the legacy `Date` object and extra libraries. Browsers need to agree on a shared, tested implementation of Temporal.

## What I did

- Submitted an Interop 2027 focus area proposal for the Temporal API to web-platform-tests/interop (issue #1381).
- Asked developers to support the proposal and describe their own use cases on the issue.

## Result

The proposal is open for the Interop 2027 selection.

## Decisions

- Argue from real developer use cases, because focus areas are chosen by evidence of developer pain.
